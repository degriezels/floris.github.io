# Floris' Mini Arcade

Een kleine, browsergebaseerde arcade met Snake. Geen backend of extra dependencies nodig.

## Starten

Open `index.html` direct in je browser, of start een lokale statische server vanuit de projectmap:

```bash
python3 -m http.server 8000
```

Open daarna http://localhost:8000. In Codespaces kun je poort **8000** previewen.

## Bediening

- Pijltjestoetsen of WASD op het toetsenbord.
- Tik op de richtingsknoppen of veeg over het speelveld op een touchscreen.
- Start, pauzeer of begin opnieuw met de knoppen. De beste score wordt lokaal in je browser bewaard.
